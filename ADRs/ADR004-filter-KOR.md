# ADR 004: Use Filters for Efficient CPA Computation

우리 시스템은 CPA 기능 수행에 대한 요구사항이 있고 고객과의 의사소통에 의해 전체 항공기에 대해 CPA 기능을 수행하거나 선택한 지역에 대해 CPA 기능을 수행할 것입니다. Experiment 4 결과 전체 항공기에 대해 CPA 기능 수행 시 연산 시간이 13.48초 걸렸습니다. 불필요한 연산을 줄일 필요성이 있어 필터를 적용하여 실험한 결과 더 나은 성능을 발휘했습니다.
 
## Decision 

비행기의 위도, 경도, 고도 정보를 활용한 필터를 적용하여 연산량을 줄이는 것으로 결정

## Rationale

모든 항공기에 대해서 충돌 위험성 평가 시 CPA 연산이 필요하지 않은 항공기에 대해서도 모두 계산하는 것은 효율적이지 못합니다. 이에 필터링을 활용하여 연산양을 줄이는 방법과 새로 업데이트된 항공기에 대해서만 CPA 결과를 업데이트 하는 방법에 대해 비교했음

- 연산이 필요 없는 항공기 필터링 방법
	- 장점 : 연산량 감소, 확장성이 높음(다양한 필터 적용 가능)
	- 단점 : 필터의 기준에 따라 충돌 가능성을 놓칠 수 있음

- 새로 업데이트 된 항공기를 기준으로 CPA를 계산하는 방법
	- 장점 : 연산량 감소
	- 단점 : 업데이트 된 항공기가 많은 경우 연산량이 많을 수 있음
 
## Status
Proposed 

## Consequences
- 구현이 간단하고 주기적으로 CPA 기능을 수행할 때 필터를 사용하는 것이 효율적이라고 판단됨
